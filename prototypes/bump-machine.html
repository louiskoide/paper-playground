What you're looking atthe parts of the machine

A neural network can copy any curve. This machine is one, built by hand: one input, a layer of hidden neurons, one output. Hover a part to find it on the machine.

  • Rail and carriage · the inputThe number x, from 0 to 1, that goes into the network. Drag the carriage to change it.
  • Lamps · the hidden neuronsEach one is a switch with its own switch point. It lights up once the input passes that point. Front row: "on" switches. Back row: "off" switches.
  • Bricks · pairs of neuronsOne "on" and one "off" switch together make a brick. Its height is how much the pair adds to the output: their output weight.
  • Dashed wire · the goalThe curve the network is supposed to copy, f(x). The closer the brick tops are to it, the better the copy.
  • Tower · the outputWhat the network answers for the current input. The dashed ring is where the goal is.
  • Screen · every answer at onceThe output for every input from 0 to 1 (orange) against the goal (dashed). The cursor is the current input.

    What the chapter saystwo claims, checked live
    You've now figured out all the elements necessary for the network to approximately compute the function f(x)! It's only a coarse approximationWith 5 pairs the average gap should be under 0.15.
    we could easily do much better, merely by increasing the number of pairs of hidden neurons, allowing more bumps.With 40 pairs the gap should be under a quarter of the 5-pair gap.

    From Michael Nielsen, Neural Networks and Deep Learning, chapter 4, "A visual proof that neural nets can compute any function", section "Universality with one input and one output". The goal is the chapter's f(x) = 0.2 + 0.4x² + 0.3x·sin 15x + 0.05·cos 50x.

    What to take away

    If a network's copy of a function is too rough, more hidden neurons can always make it better, as long as each one switches sharply.

    This is why one hidden layer is enough to compute any function, in principle. It's a proof, not a recipe: real networks learn their weights from examples instead of having them set by hand, and they rarely look this tidy inside.

    Glossary
    neuron
    A unit that takes a number in and gives a number out. Here: a switch that is off (0) or on (1).
    switch point s
    Where along the input a hidden neuron flips on. Set by its bias b = −w·s.
    input weight w
    How sharply every switch flips. Large w: an instant step. Small w: a slow ramp.
    output weight h
    How much a neuron adds to the output when it's on. A pair gets +h and −h: that's the brick's height.
    σ (sigmoid)
    The squashing function σ(z) = 1 / (1 + e^−z). It turns any number into one between 0 and 1. Every neuron here uses it.
    average gap
    The average distance between the network's output and the goal over 200 inputs. 0 is a perfect copy.
